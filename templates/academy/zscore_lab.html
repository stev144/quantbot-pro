What to notice

  • The same observation can have very different Z-scores. 104 is +2.0 against the default sample, but much smaller against the volatile one — Z depends entirely on the reference sample.
  • One outlier changes everyone. Adding 130 raises the standard deviation, so every other value's |Z| shrinks.
  • Formula: z = (x − mean) ÷ standard deviation, using the sample standard deviation (dividing by n − 1), the same convention the platform uses. With fewer than two numbers, or no spread at all, Z is undefined.
  • An extreme Z is not a forecast. A value 3 standard deviations from the average is unusual for that sample; it does not mean prices will move back. Markets have fat tails and trends, so "unusual" values happen more often than a bell curve suggests.

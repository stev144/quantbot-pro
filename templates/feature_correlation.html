How to read this matrix

1. Check the data first. Read the excluded-features table before any number. An empty column or a duplicate is a pipeline finding, not a market finding.

2. Use the stationary basis. Two series that both trended up correlate near 1 even with no shared information. Only price-free values say whether two features carry the same information.

3. Separate arithmetic from evidence. A BY CONSTRUCTION pair is high because of how the features are defined, so no data could make it otherwise. Only an EMPIRICAL pair tells you something about this market.

4. Check stability. A single full-history number can hide regimes. A narrow per-year range means the overlap is structural; a wide range or a sign flip means it depends on the period.

5. Compare Pearson with Spearman. If Spearman is much lower, a few extreme candles drive the Pearson value. If Spearman is higher, the relationship is monotone but not linear.

6. Decide. For a redundant pair, keep the feature with the better out-of-sample predictive evidence (detail page), not the one listed first. |corr| near 0 is good: the features add independent information.

Rule of thumb for |corr|: < 0.3 weak · 0.3–0.7 moderate · 0.7–0.8 strong · ≥ 0.8 treated as redundant here. With tens of thousands of candles, almost any non-zero value is statistically significant, so judge by size and stability, not p-values.
